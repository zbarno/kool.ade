### Question
Self-review cadence (CHG-006): when does Packet run the review of its own logs and the active project's planning files? Option 1 — manual only: a "Run self-review" action the operator invokes on demand. Option 2 — manual, plus one automatic run shortly after each feature reconciliation, so suggestions surface without prompting. Both options keep every Enhancement card behind the human approval button.


### Reason
It sets the final form of Scope item 1 — whether the feature needs scheduler wiring, automated busy-state guarding, and unexpected-model-spend policies before the spec can be finalized, and it changes the operator-facing promise (available on demand vs surfaces itself after milestones).


### Recommendation
Option 1 (manual only) for the first cut: cheapest, fully predictable, zero surprise model spend; Option 2's post-reconciliation hook is a small layered follow-on once the manual path earns its keep.


### Evidence
Queue and workspace controls already live in top bar / Workspace→Settings (README); D-30's Auto mode is the existing automation precedent but only for the implementation queue — no autonomous analytical runs exist; D-24's 12-hour turn budget means unattended runs need explicit scheduling policy.
