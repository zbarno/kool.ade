# Users and Outcomes

Kool.ad/e is a native desktop application for people planning software work
through conversation. It helps a user turn an unclear goal into a reviewed
specification and focused implementation tasks.

## Primary outcome

The user can understand the current product direction, resolve open decisions,
approve a plan, and track implementation through review and QA evidence.

## Authority

The connected user is the decision maker. Recommendations remain advisory until
the user explicitly adopts them. Task discussions, approvals, and operational
evidence stay private on the user's machine.
