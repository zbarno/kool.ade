# Current Capabilities

Kool.ad/e supports conversational planning, focused TaskIntents and child
tasks, local task conversations, plan review, isolated implementation clones,
pull request review, and task-bound QA evidence.

The board presents active work and attention items. Users can inspect task
history, answer questions in the corresponding conversation, and resume work
after an application restart.

Capability claims describe the current application. Provider integrations,
native-host behavior, release readiness, and live remote behavior require their
own validation evidence.
