# Full Rust test inventory

`full-suite.csv` lists the 1,940 test cases from `cargo +1.98.1 nextest list --locked --all-targets --message-format json` at `489f36af5739d933a7930efd0c0dec85ada8872d` (`main`, 2026-10-16). Outcomes and per-case durations come from successful [CI quality run 38873722485](https://github.com/zbarno/kool.ade/actions/runs/38873722485) on the identical source tree: 1,938 passed, 2 skipped, 0 failed. Its measured nextest wall time was 183.799 seconds from `time -p`; the complete tests and Docker runtime job took 401 seconds including setup, compilation, and teardown. CI runs the suite with 16 nextest threads. The earlier 307.28-second run on the prior snapshot is a separate observation, not a before/after speedup claim.

Each row records the test ID, source location and mapping method, test-name intent label, category and dependency signals, duration, result, same-name overlap candidate, and current review decision. Source locations were matched by module path for 1,874 tests; the other 66 unique-function matches were checked against the Rust sources. The inventory and generator record that mapping explicitly. This verifies locations only; generated category, dependency, and intent values remain name/path signals. Invariant-level review is pending for rows marked pending, while reviewed rows record their decisions and evidence. The generated intent label is the test name, not a reviewed invariant description.

Two same-name pairs (four test cases) remain and were reviewed. The two archive diagnostic cases exercise separate staging paths; the Cargo and npm cache cases exercise separate implementations. PR #215 removed two exact duplicate feature-approval test copies and kept their canonical counterparts. The removed copies summed to 23.141 test-seconds in the pre-consolidation #213 report. This current inventory does not contain those removed tests, and the available timing comparisons do not establish a full-suite wall-time reduction from their removal.
