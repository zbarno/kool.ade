MEET KOOL.AD/E MAN.AGER

Your slightly obsessive technical project manager.

No relation.

Kool.ad/e Man.ager sits between you, your repository, and the coding agents doing the work. It pulls ambiguity forward, maintains the spec, turns approved plans into ordered work, watches implementation, and asks for human judgment only when it actually needs it.

Less “AI pair programmer.” More “project manager who has read the entire repo and would really like everyone to stop improvising the acceptance criteria.”

Prefers Git worktrees to entering rooms through the wall.

THE BOARD IS THE INTERFACE

One giant chat is not a project plan.

Questions, assumptions, decisions, blockers, implementation tasks, and reviews live as first-class items. Each gets its own focused conversation and context.

WHAT'S IN THE PACKET?

Guardrails, not magic.

Kool.ad/e is deliberately boring about the parts that should be boring. Project knowledge lives in Markdown and Git. Implementation happens in isolated worktrees. Verification commands are explicit. Publication is a separate decision.
